# Mani House with Sea View

Static website for [Mani House with Sea View](https://manihousewithseaview.gr), a traditional stone house in Neochori, Stoupa, on the Mani Peninsula (Greece). Served with GitHub Pages.

## Structure

* `index.html`: the one-page site (house, surroundings, contact)
* `imprint.html`, `privacy-policy.html`, `cookie-policy-eu.html`: legal pages
* `404.html`: page shown for unknown URLs
* `style.css`: all styling
* `images/`: photos in two sizes (800 and 1400 px on the longest side) plus logos
* `fonts/`: self-hosted Alegreya and Alegreya Sans, so no external font service is contacted

The site uses no cookies, no tracking and no external scripts.

## Editing

Edit the HTML files directly. New photos go into `images/` in both sizes, for example with macOS `sips`:

```
sips -Z 1400 photo.jpg -s formatOptions 55 --out images/name-1400.jpg
sips -Z 800 photo.jpg -s formatOptions 60 --out images/name-800.jpg
```
